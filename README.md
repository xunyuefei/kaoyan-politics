## 💻 桌面独立窗口 (PWA) 安装与使用指南

本图谱完全支持 **Progressive Web App (PWA)** 标准规范：

### 1. Edge 浏览器
1. 访问网页后，点击地址栏右侧的 **「应用可用」图标 ➕**。
2. 或按快捷键 `Alt + F` ➔ 选择 **「应用」** ➔ 点击 **「将此站点作为应用安装」**。
3. 勾选 **「在桌面上创建快捷方式」** 与 **「固定到任务栏」**。
4. 随后即可从桌面双击专属图标，以纯净无边框的独立软件窗口运行！

### 2. Chrome 浏览器
1. 访问网页后，点击地址栏最右侧的 **「安装 考研政治·经纬图谱」图标 ⊕**。
2. 或点击右上角菜单 **「⋮」** ➔ **「保存并共享」** ➔ **「安装应用」**（或「创建快捷方式」，勾选「在独立窗口中打开」）。

## 🚀 部署到 GitHub Pages

项目已内置自动化流水线 `.github/workflows/deploy.yml`。

在 GitHub 仓库的 **Settings ➔ Pages** 中：
- **Source** 选择：`GitHub Actions`
- 只要向 `main` 分支推送代码，GitHub Actions 会自动部署发布到：
  `https://<你的用户名>.github.io/<仓库名>/`
